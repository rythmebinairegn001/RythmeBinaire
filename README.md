# RythmeBinaireGn

Plateforme e-learning bilingue FR/EN (React + Vite + Supabase).

## Lancer en local
1. `npm install`
2. Copier `.env.example` en `.env.local` et renseigner les clés Supabase
3. `npm run dev`

## Déployer (Vercel)
Preset **Vite**, variables `VITE_SUPABASE_URL` et `VITE_SUPABASE_ANON_KEY` à définir dans Vercel.
